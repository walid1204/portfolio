DigiCow Farmer Training Adoption Challenge

Solution Documentation

1) Overview & Objectives

The goal is to predict adoption probabilities within 7, 90, and 120 days after a farmer's first training, using only information available at the time of training. The solution outputs calibrated probabilities for the required targets and generates a submission CSV matching the competition format.

2) ETL Process

Extract

  • Reads the provided CSV files (Prior.csv, Test.csv) using pandas.
  • Input format is standard CSV.

Transform

  • Data cleaning and type coercion (dates, missing values).
  • Normalization of list-like fields (e.g., training topics).
  • Construction of deterministic event-level records for training and test.

Load

  • All intermediate tables are kept in-memory as DataFrames.
  • The final result is exported as a submission CSV.

3) Data Modeling

Feature Engineering

  • Categorical and group-level aggregations (e.g., farmer / trainer / topic aggregates).
  • Time-derived features from training dates.
  • Text-derived topic representations using TF-IDF and dimensionality reduction (SVD).

Models

  • CatBoostClassifier
  • XGBoost (XGBClassifier)
  • LightGBM (LGBMClassifier)
  • Stacking meta-model: LogisticRegression on base model predictions

Validation

  • GroupKFold cross-validation (5 folds) to reduce leakage across grouped entities.
  • Metrics monitored during development: Log Loss and ROC-AUC (as per competition rules).

4) Inference

The trained ensemble produces raw probabilities for each required target column. No thresholding or rounding is applied.

5) Runtime

End-to-end runtime (data processing + modeling + inference): ~51 minutes on CPU.

6) Error Handling & Logging

  • The code prints progress messages for major stages.
  • If required files are missing, the runner script fails fast with a clear error message.

7) Maintenance & Monitoring

For production use, recommended checks include schema validation, drift monitoring on feature distributions, and periodic retraining when data shifts are detected.
